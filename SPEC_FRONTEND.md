# Frontend spec
Next.js + React + TypeScript. Pages: landing, docs, sign-up/login, dashboard (submissions, validation status, entries), race calendar, live viewer, replay viewer, leaderboard, public profiles, admin.
Live viewer: canvas/WebGL track, numbered coloured cars, timing tower (position, gap, last lap, tire), lap counter, event feed (overtakes, pits, penalties, incidents), replay speed/seek. Accessible, responsive, light/dark. Never trust the client; all authority is server-side.
